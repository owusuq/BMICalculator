# Overview

Before jumping into anything more complex, I wanted to make sure my basic setup actually worked: Git, GitHub, and my C# toolchain, all the way through to a published repo. This is the boring-but-necessary step most tutorials skip past, and skipping it is usually how people end up debugging their environment instead of their code later on.

This repo is about as simple as software gets - a "Hello, World!" program in C#. There's not much to the code itself. The real goal was proving out the workflow: write it, document it, record a walkthrough, and get it live on GitHub.

[Software Demo Video](https://youtu.be/b9K5Gd39Yio)

# Development Environment

I wrote and ran this locally in Visual Studio Code with the C# Dev Kit extension, using the .NET SDK to build and run it from the command line. Git tracked the changes, and the finished code is published on GitHub.

The program itself is written in C#.
